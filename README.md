# stage2A
## Dossiers : 

### Matlab 
Codes et données de test de la partie réalisée en Matlab. Cette partie comprend les premières pistes de recherche : 
- Variations de la somme des valeurs singulières
- Traitement des images en amont (masque, rognage, tuilage, RGB vs Gris)

### Lowrr
Fichiers et données de test pour la traduction en Python du code Rust sur la correction des micro-mouvements de caméra.
    
### Python
Codes et données de test de la partie réalisée en Python. Cette partie comprend les pistes de recherche suivantes :
- Utilisation de la SVD avec l'hypothèse de rang 3
- Double vérification des indices de changement de pose
- Variations locales / globales (au niveau de la norme)
- Utilisation des points d'intérêt (SIFT, ORB)
- Post-validation par l'utilisateur
- Traitement des images en amont (pyramide, tri des images avec fichier EXIF, éclairage)

### Temp
Dossier contenant tous les fichiers en vrac. Les dossiers Matlab, Lowrr et Python sont organisés à partir des fichiers de Temp.
